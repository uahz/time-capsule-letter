# 给未来写信

> 写一封信，设定一个未来日期。到了那天，系统日历提醒你打开。

**纯前端 · 单 HTML 文件 · ICS 日历导出 · 离线可用 · PWA 可安装到手机桌面**

## 功能

- **写信**：无格式化 Markdown 风格，专注写内容
- **设定日期与时间**：日期选择器 + 时间选择器（早 9 / 中午 / 傍晚 / 晚 9 / 午夜）
- **心情标记**：8 种情绪表情（😊😢😤😌🥰😴🌈🌧），选填
- **信名**：最多 40 字，方便在信筒里辨认

### 核心功能：ICS 日历导出

点击「导入日历」生成 .ics 文件，下载后双击即可导入到：

- **Windows**：系统日历 / Outlook
- **macOS**：系统日历 / Google Calendar
- **Android**：Google 日历 / 各品牌自带日历
- **iOS**：系统日历

导入后自动设置 **提前 30 分钟提醒**，到点系统弹通知，无需服务器。

### 信筒

- 自动存档最近 **10 封**
- 「已抵达 / 等待送达」状态分色显示（绿/金）
- 点击可重新打开阅读
- 全部存在浏览器 localStorage，不经过任何服务器

### 其他操作

- **复制文字**：纯文本格式
- **下载 .txt**：离线备份

## PWA

- manifest.json：配置名称、图标、主题色、竖屏锁定、独立窗口
- Service Worker：注册即缓存，断网也能开

## 安装使用

### PC

直接在浏览器打开 index.html。推荐用 Edge / Chrome 地址栏右上角的「安装」按钮，添加为独立窗口应用。

### Android（PWA 安装）

`ash
# 在项目目录启动本地服务器
python -m http.server 8765

# 或
npx serve -p 8765
`

1. 手机通过同一局域网访问 http://你的IP:8765
2. Chrome 菜单 → 添加到主屏幕
3. 桌面出现图标，打开后无浏览器栏

### 离线

首次访问后 Service Worker 自动缓存，断网时重新打开仍能正常使用。

## 关于「定时送达」的设计决策

> **为什么不用后端发邮件？**

本项目的核心理念是**零后端、零服务器、零成本**。

ICS 日历导出方案：
- 不需要注册 / 登录 / 邮箱
- 不需要服务器定时任务
- 数据 100% 在本地
- 系统日历提醒的可靠性高于任何自建定时任务

> **那到了那天真的能收到吗？**

能，前提是将 .ics 文件导入到了你的系统日历中。手机和电脑的日历应用都会在设定的时间弹出通知。绝大多数现代操作系统和手机品牌都支持标准 ICS 格式。

> **如果我想加后端呢？**

项目架构使得在未来添加云存储 + 邮件发送变得容易。目前专注在**最小可用、最隐私友好**的版本上。

## 技术栈

| 层 | 选用 |
|---|---|
| HTML 模板 | 纯手工 |
| 样式 | 原生 CSS（变量 + 媒体查询） |
| 日历生成 | 手写 ICS 文件（iCalendar 标准格式，RFC 5545） |
| 持久化 | localStorage（自动存 10 封） |
| PWA | manifest.json + Service Worker（Cache First） |

## ICS 文件格式说明

生成的 .ics 文件包含：

`
BEGIN:VCALENDAR
VERSION:2.0
BEGIN:VEVENT
DTSTART:20380315T090000     ← 送达日期
SUMMARY:📬 给 30 岁的自己    ← 信名
DESCRIPTION:正文内容        ← 信的内容
BEGIN:VALARM
TRIGGER:-PT30M             ← 提前 30 分钟提醒
ACTION:DISPLAY
END:VALARM
END:VEVENT
END:VCALENDAR
`

完全遵循 RFC 5545 标准，兼容主流日历应用。
